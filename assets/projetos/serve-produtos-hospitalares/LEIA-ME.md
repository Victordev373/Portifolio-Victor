# Imagens deste projeto

Coloque aqui 3 arquivos `.webp`:

- `capa.webp` — miniatura usada como capa/prévia do projeto
- `completo.webp` — print da página inteira (versão desktop), usado no mockup do notebook
- `mobile.webp` — print da versão mobile, usado no mockup do celular

Enquanto os arquivos não existirem, o site mostra automaticamente um
fundo com a cor do projeto no lugar do print (nenhum link quebrado).
